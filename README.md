# RightKit

RightKit 是一个 macOS Finder 右键菜单增强工具。本仓库用于在原始源码缺失的情况下，依据现有应用、界面观察和可重复验证，重建产品知识并为后续实现做准备。

当前参考对象是 `/Applications/RightKit.app`，版本 `1.0.0`（build `1`），最低系统要求为 macOS 14。已确认应用包含原生 Swift 主程序和 Finder Sync Extension。仓库目前处于研究与规格阶段，不包含重建后的应用代码。

## 当前边界

- 已完成所有设置页，以及 Finder 工具栏、空白处和单选文本文件菜单的实时 Accessibility 界面检查。
- 已从安装包字符串补充少量能力线索。
- 已在隔离测试文件上跑通文件哈希，并与 Python 标准库结果逐项核对。
- 尚未执行其余大部分右键菜单功能，因此界面中存在入口不等于运行结果已验证。
- 文档中的开关状态是观察当时的配置，不代表产品默认值。
- 未确定发布渠道、新 bundle ID、签名方案，以及主程序与扩展之间的通信方式。
