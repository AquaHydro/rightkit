# 验收

验收对象是本仓库构建的 RightKit，不是机器上的其他应用。功能含义以 [功能规格](features.md) 为准。

## 通用规则

- 使用开发 bundle ID 和独立的设置目录。
- 文件操作用每次新建的临时目录。永久删除只删除测试自己创建的文件。
- 菜单规则、重名、保护路径和哈希向量放在 `RightKitCore` 测试里。
- 需要真正打开访达的项目，单独记录系统版本、操作步骤和结果。做不到时标为阻塞，不要改预期。
- Finder 验收记录还要包含构建提交、监视目录和扩展菜单回调日志。

状态：`Planned` 还没跑，`Passed` 符合预期，`Failed` 不符合，`Blocked` 当前环境做不了。每次真机验收的步骤、日志和未覆盖项见 [验收记录](verification-log.md)。

## 哈希向量

`V-043` 使用这段 UTF-8 字节，共 26 字节，内容是 `RightKit research fixture` 加一个换行：

| 算法 | 值 |
| --- | --- |
| MD5 | `e4456d16d449ba7863b647d453a943a8` |
| SHA-1 | `b75630a2350283ae79e7783f3220d813556c3f6f` |
| SHA-256 | `b498f016419a7033869370c685746066601370413988cf11760d56e6d01d32bb` |
| SHA-512 | `d9c01d63a6f36102ca19b74e032fef0b95a5ef4d4b918ebd800b90090792a8769561b2f9e25edf09509955ecc91203cfa17d56a44ee81adc153be4349f5064c7` |

空文件的四个结果必须等于对零字节数据计算的标准值。

## 必须覆盖的菜单情况

`V-050` 至少覆盖：监视目录内的无选择、空白处、一个文件夹、一个文本文件、一张图片、多个文件夹、文件和文件夹混合、功能组关闭、命令关闭、有待粘贴项，以及监视目录外的空白处。工具栏由 `V-003` 覆盖。预期以功能规格里的两张表为准。
