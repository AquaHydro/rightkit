# 现有应用调研记录

日期 2026-09-22；对象 `/Applications/RightKit.app` 1.0.0 (1)。调研机 macOS 27.0 (26A428)，已安装 Xcode。安装包构建信息为 Xcode 26.5 / macOS SDK 26.5，最低系统 14.0。观察环境不能替代 macOS 14 或 26 上的验证。

## 方法和证据等级

1. 实时 UI：使用原生无障碍树逐页查看通用、新建文件、在应用中打开、常用目录、发送到、工具箱、关于；视觉检查关于页。
2. 实际菜单：观察 Finder 工具栏、空白区域、单选文本文件菜单。
3. 实际操作：仅在仓库内隔离目录测试文件信息哈希，和 Python 标准库对照。
4. 安装包静态证据：Info.plist、权限、动态库、模板文件名、本地化、少量通信标记。

配置开关只证明入口和当前状态；文案/符号只证明存在相应资源。没有声称所有功能已测试，也没有从二进制恢复源码。没有重置旧版配置、重启 Finder、执行删除/权限修改或发送翻译文本。

## UI 观察摘要

[功能清单](features.md)承载完整条目。设置窗口为左侧七页导航、底部重启/退出、右侧内容，浅色界面有淡色背景、彩色图标及强调色。关于页显示版本、两项系统/重启入口。只检查当前外观，没有验证夜间、系统主题切换、玻璃回退及全部拖拽交互。

### Finder 实际菜单

| 上下文 | RightKit 菜单内容 |
| --- | --- |
| 工具栏无选择 | 新建文件；常用目录；在应用中打开；拷贝当前路径；显示/隐藏隐藏文件；RightKit 设置 |

新建子菜单出现六种当前启用模板；复制到和移动到包含配置目录以及“选择文件夹…”。文本文件工具箱出现拷贝路径、拷贝名称、根据文件名新建文件夹、发送替身到桌面、隔空投送、隐藏/显示所选、显示/隐藏扩展名、授予写入权限、文件信息（哈希）、彻底删除、显示/隐藏隐藏文件。

**差异记录**：常用目录设置文案称“任意位置”，但单选文本文件菜单没有该组。中文设置中模板和目录为中文，而实际菜单对应名称是英文。把这两项作为待决定的兼容差异，不自动复刻成要求。

### 哈希闭环

创建 `.research-fixtures/sample.txt`，UTF-8 内容为 `RightKit research fixture` 加 LF，共 26 字节。在该文件的 Finder 右键工具箱中执行“文件信息（哈希）…”，先显示“正在计算哈希…”，随后显示文件名、大小、四项哈希与独立拷贝按钮。

实际观察值与独立计算的逐项比较见 [hash-result.json](evidence/hash-result.json)，预期值见 [hash-expected.json](evidence/hash-expected.json)。这证明当前运行实例的此条 Finder → 主程序 → 文件读取 → 展示路径已跑通，不证明多选、大文件或权限错误处理。
