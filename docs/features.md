# 功能清单

本文档是 RightKit 功能编号和证据状态的主索引。功能编号一经分配不得复用。

## 证据等级

| 等级 | 含义 | 可得出的结论 |
| --- | --- | --- |
| `L1` | 实时 Accessibility 界面观察 | 确认设置入口、标签、可选项、观察时状态和指定上下文中的菜单可见性 |
| `L2` | 安装包资源或字符串静态证据 | 确认应用包含相关文本或资源，不能单独证明功能可执行 |
| `L3` | 可重复的功能执行验证 | 确认指定环境、输入和步骤下的实际行为 |

当前仅文件哈希的单文件路径具有 `L3` 结果。除非功能条目标记为 `L3`，本文档不承诺菜单结果、格式内容、多选行为、冲突处理或错误处理。

### 已观察到的菜单差异

- 工具栏无选择时，“新建”显示 6 个当前启用模板，“常用目录”显示当前目录项；模板名和目录名为英文，菜单分组为中文。
- Finder 空白处右键菜单没有“RightKit 设置”，其余已观察分组与工具栏无选择菜单一致。
- 单选 `sample.txt` 时，“复制到”和“移动到”包含收藏目标及“选择文件夹…”入口。
- 设置界面的“任意位置”描述与实际观察不完全一致：单选 `sample.txt` 时没有出现“新建”和“常用目录”。在更多上下文验证前，此差异保持为已知问题，不能用设置文案推断菜单展示。

## 尚未确认

- 首次启动时的默认设置。
- Finder 菜单的完整层级、排序、图标和所有上下文匹配条件。
- 除已记录的无选择、空白处和单选 `sample.txt` 可见性外，其他单选、多选、文件夹和混合选择行为。
- 新建文件的实际内容、格式有效性、命名与重名策略。
- 文件操作的冲突、权限、符号链接、撤销和错误提示行为。
- 二维码与翻译能力的真实入口、依赖和失败处理。
- 发布渠道、更新机制、授权或付费机制。
