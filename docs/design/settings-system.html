组件

分段标签

放在标题栏中央，取代系统设置窗口的工具栏图标。最多 5–6 项，超出时横向滚动。

带标签的下拉框

标签用 text-3（≥ 4.5:1），不用 magpie 那种 30% 透明度的灰。值为默认时用 text-2。

按钮

一个区块最多一个突出按钮。文字按钮只用于次要的添加类操作。

状态与开关

已启用 未启用

状态点旁边一定配文字。开关打开时用系统绿，跟随“增强对比度”设置。

规则

每个分组一张卡片，行与行之间只用发丝线分隔；分组标题放在卡片外面。
窗口可缩放：内容区滚动，标题栏和底栏固定不动。窄窗口时控件移到标题下方，而不是截断文字。
行首图标用 18% 透明度的着色底块，颜色表示含义（蓝：通用，绿：新建，红：有破坏性）。
不要在下拉框里用低于 4.5:1 对比度的标签文字，也不要只靠颜色表达状态。
不要写死窗口尺寸；SwiftUI 里用 .frame(minWidth: 380, idealWidth: 680, minHeight: 360) 加 .windowResizability(.contentMinSize)。
