# 官网设计

RightKit 产品介绍页的结构、视觉、动画和素材。角色设定见[品牌角色设定](brand-character.md)，功能描述以[功能规格](../features.md)为准，官网不写规格里没有的功能。

## 目标

1. 五秒内讲清楚：RightKit 让访达的右键菜单能新建文件、复制移动到常用位置、用指定应用打开，还带一组文件工具。
2. 让人记住角色和珊瑚色。
3. 下载 DMG。官网是唯一分发渠道（见[工程边界](../technical.md)），需要 macOS 26 或更高版本。

## 参考与取舍

版式参考 [cindy.app](https://cindy.app/)。2026-09 实测它的做法：

- 深色区块和米白区块交替，中间穿插满宽的纯色大区块。全站只有深色、米白和一种品牌色。
- 每节开头一个等宽小标签（`// 01  MULTI-HARNESS`），编号用品牌色，后面拉一条细线。
- 角色出场两次：首屏 Hero 和结尾下载区，中间各节只用排版和卡片。
- 首屏字标用「灯管通电」式闪烁出场，文字上升、立绘侧滑进场。常驻动画幅度小、周期长。滚动进场统一用一条 expo-out 曲线。支持减弱动态效果。
- 纯 CSS 动画加少量 JS，没有 WebGL 和视频。

RightKit 照搬结构和节奏，不照搬气质：Cindy 的故障、扫描线、赛博朋克风格和我们的圆润可爱图标不搭。我们的动效都围绕「右键」这一个动作来设计。

## 视觉

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#2A2B31` | 深色区块背景，图标底色 |
| `--ink-2` | `#34353C` | 深色区块上的卡片 |
| `--paper` | `#FAF7F5` | 米白区块背景 |
| `--paper-2` | `#F2ECE8` | 米白区块上的卡片 |
| `--coral` | `#FF7973` | 品牌色：编号、强调文字、按钮 |
| `--coral-start` / `--coral-end` | `#FF8F6C` / `#FF5175` | 珊瑚渐变，只用于大色块和按钮 |
| 意图色 | 创建绿、前往橙、拷贝蓝、移动青、查看灰、外观紫 | 只出现在模拟的右键菜单里，和[菜单设计系统](menu-system.html)一致 |

红色只表示「彻底删除」，官网不拿红色做装饰。深色和浅色区块交替出现，所以官网本身不做主题切换。珊瑚底上的白字要达到 4.5:1，不够就用 `--ink` 色的文字。

### 字体

| 用途 | 字体 |
| --- | --- |
| 字标、大标题（拉丁字母） | 圆润的粗体，推荐 Nunito 900 或 Fredoka 700，和图标的圆角一致 |
| 中文标题和正文 | 系统字体栈：`-apple-system, "PingFang SC", "Hiragino Sans GB", sans-serif` |
| 小标签、文件名、快捷键 | 等宽，推荐 Geist Mono |

网页字体只加载拉丁字母子集，中文走系统字体，不下载中文字库。

### 版式

- 内容最大宽度 1200px，两侧留白至少 24px（手机 16px）。
- 每节开头的小标签：`// 01  新建`，等宽字体、字间距 0.2em、编号用珊瑚色，右侧拉一条 1px 细线。
- 区块之间用一条带珊瑚色小圆点端点的细线过渡。
- 卡片圆角 16px，和 macOS 26 的窗口圆角气质一致。

## 标志性交互：可以右键的首屏

Hero 右侧放一个模拟的访达窗口（HTML 和 CSS 绘制，不用截图）。访客在这个区域里右键（触屏长按，键盘可以用 Shift+F10 或一个显式按钮）会弹出 RightKit 菜单：

- 菜单项和真实菜单一致：新建、拷贝到、移动到、在应用中打开、工具箱，图标用意图色。
- 点「新建 > Markdown」，窗口里出现一个「未命名.md」并进入重命名状态。点其他项播放对应的简短演示。
- 只在这个区域内拦截右键，页面其他地方保留浏览器默认菜单。
- 首次进入时自动演示一次：光标移到文件上，右键，菜单展开，停在「新建」。访客一操作就停止自动演示。

这就是 Hero 立绘需要分层的原因：角色是一张透明图，菜单和窗口是代码，可以动、可以点、可以翻译。

## 动画

全站只用一条主曲线：`--ease-out: cubic-bezier(0.16, 1, 0.3, 1)`。

| 场景 | 效果 | 时长 |
| --- | --- | --- |
| 开屏 | 光标从右下滑入，「点」一下（缩放 0.9 再回弹），菜单展开，菜单项从上到下依次亮起，每项间隔 40ms；接着字标出现，标语上升 24px 淡入，角色从右侧滑入 32px | 总计约 1.4s，单项 0.6 到 0.9s |
| 角色常驻 | 上下浮动 8px | 7s 一个周期，ease-in-out |
| 发卡 | 发卡上的小光标每 8 秒「点」一下，旁边三条横线依次闪一下 | 0.4s，其余时间静止 |
| 小白鼠 | 每 10 秒左右眨一次眼（替换一帧或用遮罩） | 0.15s |
| 跑马灯 | 匀速滚动 | 36s 一圈 |
| 滚动进场 | 元素进入视口时上升 24px 淡入，同一组卡片错开 60ms | 0.7s |
| 按钮 hover | 上移 1px，阴影加深 | 0.18s |
| 菜单展开 | 从光标位置缩放 0.96 到 1 并淡入，和 macOS 菜单一致 | 0.18s |

规则：

- 只动 `transform` 和 `opacity`，不动布局属性。
- 常驻动画在区块离开视口时暂停。
- `prefers-reduced-motion: reduce` 时关掉浮动、跑马灯和开屏序列，元素直接显示在最终位置，菜单演示改成静态截图。

### 已有素材待修改

来自 [AquaHydro/rightkit#2](https://github.com/AquaHydro/rightkit/pull/2) 的审查：

1. **Q 版小插图的地面阴影**是半透明的浅粉灰色，放在深色区块上像一圈光晕。去掉阴影，由 CSS 在脚下画。
2. **画布尺寸和角色比例不统一**：3 张是 1024 × 1536，`feature-copy-move` 是 1191 × 1321，`feature-open-app` 是 1175 × 1339，而且 `feature-open-app` 里的角色明显更小。统一成 1024 × 1536，头顶和脚底对齐。
3. **`feature-empty-error` 的文件夹是黄色**。规范要求普通蓝色文件夹，局部重绘成蓝色。
4. **`feature-open-app` 里的锁是偏红色**。红色专指彻底删除，改成珊瑚色或中性灰。
5. **抠图主体不是完全不透明**：6 张透明 PNG 的主体像素 alpha 多为 252 到 254，放在有纹理的背景上会微微透底。导出时把 alpha ≥ 250 的像素设为 255。
6. **体积**：透明 PNG 每张 1 到 1.6MB。网页引用导出后的 WebP，立绘不超过 200KB，小插图不超过 120KB，同时准备 1x 和 2x 两种尺寸。

## 技术

- 静态站，放在 `website/`。不引入重型框架；需要组件化时优先用 Astro 这类默认零运行时的方案。
- 中英两个语言版本，路径 `/` 和 `/en/`，文案放在同一份数据文件里，按浏览器语言给出切换提示，不自动跳转。
- 首屏立绘用 `<img fetchpriority="high">` 并预加载；其他图片懒加载。
- 性能预算：首屏传输量不超过 500KB，移动端 LCP 在 2.5 秒以内。

## 验收

1. 桌面（1440 × 900）和手机（390 × 844）两种宽度下截图，没有横向滚动，Hero 标题不被角色遮挡。
2. 首屏模拟窗口可以用鼠标右键、触屏长按和键盘三种方式打开菜单；页面其他地方的右键行为不变。
3. 开启「减弱动态效果」后没有浮动、跑马灯和开屏动画，内容完整可见。
4. 所有文字和背景的对比度达到 WCAG AA。
5. 页面上的每一项功能描述都能在功能规格里找到对应的 `F-xxx`。
6. 中英两版文案都没有 em dash。
